```tsx
  return (

        <p>• 搜索文档</p>
        <p>• 评估方案</p>
      </div>
    </Think>
  )
}
```

## API 参考

### 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `React.ReactNode` | `"Thinking..."` | 状态栏显示的标题 |
| `icon` | `React.ReactNode` | - | 自定义图标（会被 loading 覆盖） |
| `loading` | `boolean \| React.ReactNode` | `false` | 显示加载状态或自定义加载器 |
| `defaultExpanded` | `boolean` | `false` | 初始展开状态（非受控） |
| `expanded` | `boolean` | - | 受控展开状态 |
| `onExpand` | `(expand: boolean) => void` | - | 展开状态变化回调 |
| `blink` | `boolean` | `false` | 为状态栏添加脉冲动画 |
| `prefixCls` | `string` | `"think"` | CSS 类名前缀 |
| `className` | `string` | - | 根元素额外的 CSS 类名 |
| `rootClassName` | `string` | - | 根元素 CSS 类名 |
| `classNames` | `Partial<Record<SemanticType, string>>` | - | 语义部分的 CSS 类名 |
| `styles` | `Partial<Record<SemanticType, React.CSSProperties>>` | - | 语义部分的内联样式 |

### 语义类型

组件暴露三个语义插槽：

- `root` - 最外层容器
- `status` - 头部/状态栏区域
- `content` - 可展开的内容区域

### Ref 引用

组件 ref 暴露：

```tsx
type ThinkRef = {
  nativeElement: HTMLElement | null
}
```

## 特性

✅ **可展开/收起** - 基于 Radix Collapsible 构建  
✅ **加载状态** - 自动集成骨架屏  
✅ **受控/非受控** - 灵活的状态管理  
✅ **自定义图标** - 支持任意 React 节点  
✅ **闪烁动画** - 处理过程中的视觉反馈  
✅ **语义化样式** - 精细的样式控制  
✅ **键盘可访问** - 完整的无障碍支持
